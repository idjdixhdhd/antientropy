## 二、人话版：三段式（保留原文 + 学术解释 + 术语词典）

> 你质疑"一两句解释不清"——对。改成**够详细的三段式**，复杂内容允许写 4-5 句。

**每张卡（默认折叠原文区，卡片干净）：**

```
┌──────────────────────────────────────┐
│ OpenAI · AI前沿 · 2026-08-19   展开原话 ▾│
│ GPT-5.6 推出"Ultrafast"极速模式，快 14 倍 │
│                                          │
│ 大白话：OpenAI 发了个新模型版本，跑得比原来快 14 倍。│
│   这对你有两层意思：① 服务器成本降了——同一任务       │
│   更快做完，费用更低；② 你用的 AI 产品会更"秒回"，      │
│   尤其适合语音助手、实时翻译这种不能等场景。            │
│                                          │
│ ▸ 展开原话（点开才显示）：                        │
│   原文：Previewing Ultrafast mode: GPT-5.6 Sol   │
│         at up to 14X the speed.                │
│   术语：Ultrafast=实时低延迟模式                   │
│        Sol=专供速度的推理模型变体                  │
│        reasoning model=会"先想后答"的模型          │
│                                          │
│ [复制全文] [收藏]              [打开原文 ↗]      │
└──────────────────────────────────────┘
```

**Prompt 规则（写死给 DeepSeek）**：
- 标题：通俗中文 ≤20 字
- 大白话：2-4 句，讲清"是什么 / 为什么 / 跟你有什么关系"，**学术信息不删**，只换说法
- 原文：保留英文关键句（1-2 句）+ 中文对照
- 术语：3-5 个专有名词通俗化解释
- 禁止编造，禁止只给结论不给依据

## 五、自动抓 · Cloudflare Worker Cron 全闭环（token 你已确认继续用）

```
Cloudflare Worker Cron（每天 08:00 北京时间）
  ├─ 抓 40+ 源 RSS（动态轮询间隔）
  ├─ 语义过滤（/filter：保留感悟/干货，丢弃攻略/快讯/融资）
  ├─ DeepSeek 翻译（三段式人话版，保留原文+术语）
  ├─ 写 news.json（GitHub Contents API）
  └─ Pages 自动重建 → 你看到的就是每天新的、中文完整版
```

- 你**完全不需要访问 workers.dev**（Cron 后台触发），只刷 github.io
- 关键点：AI 翻译产物直接写进 news.json，**你看的是成品中文**，不用点任何按钮
- 失败兜底：源失败跳过、DeepSeek 失败保留原文、全部失败保留上次数据
