## 三、宣传片分镜（自由模式 · 60 秒 · 桌面端演示）

> 视觉风格参考"安妮少女站"——清新、克制、文艺。
> 配色沿用网站主题（薄荷绿 + 暖灰 + 深色背景）。

### 时间轴

| 时间 | 画面 | 屏显文字 | 旁白（可选） |
|---|---|---|---|
| **0:00-0:05** | 黑屏 → 缓慢打字机浮现 | "你还记得，昨天做了什么吗？" | 安静 |
| **0:05-0:10** | 淡入逆熵 logo + 品牌名 | "逆熵 · ANTIENTROPY" | 主题音乐起 |
| **0:10-0:20** | 主线复利面板：空曲线 → 一个点 → 慢慢起伏 | "记下一点，曲线就长一格。" | "记下 |
| **0:20-0:30** | 今日必须完成：勾选任务的小动画 | "做完就勾掉。明天再写新的。" | "做完 |
| **0:30-0:38** | 身体账户：水位从空到半满 | "每天存几个好习惯，水位就涨。" | "每周 |
| **0:38-0:48** | 微光：一条一条加入，柔光 | "记下你做过的小事。20 件亮一次。" | "记下 |
| **0:48-0:55** | 灵感雷达：卡片滑入 + "译" 按钮高亮 | "每天看点世界在发生什么。看不懂一键译。" | "精选 |
| **0:55-1:00** | 6 个面板快速过一遍 → antientropy.pages.dev | "逆熵 · 把熵倒着走" | 收尾 |

### 关键元素

- **背景音乐**：钢琴 / 环境音（参考 QUIETNATURE 网站调性）
- **转场**：淡入淡出为主，少用硬切
- **字幕**：用页面截图字体（半透明深色背景 + 白色字）
- **logo 动画**：渐显 + 轻微呼吸感缩放
- **彩蛋**：60 秒末尾预留 5 秒，无文字，只显示一条"上周 X 人已访问"
